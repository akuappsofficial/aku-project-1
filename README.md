# Aku — Static Grok Chat

Browser-only chatbot powered directly by the xAI Grok API.

No backend, server, database, Node runtime, or API proxy.

Open index.html directly or deploy as a static site. Configure the API key in Settings.

Features: streaming responses, local chat sessions, local settings, responsive mobile UI, model selection, and API error handling.

Security: because the app is client-side, the API key is exposed to the browser and stored in localStorage. Do not use a sensitive personal key in a public deployment.

# Aku AI

JavaScript AI chat app powered by Groq.

## Run

1. Copy .env.example to .env.
2. Set GROQ_API_KEY in the server environment.
3. npm install
4. npm start
5. Open http://localhost:3000

The API key stays server-side and is never committed or exposed to browser code.

Features: Groq chat, Chatbot/Code modes, sessions, browser memory, live request status, responsive UI, and server health settings.
